# Devices

Reusable device wrappers that abstract hardware controllers behind clean
interfaces so subsystems never depend on vendor-specific APIs.

## Subfolders

| Folder   | Purpose                                                          |
| -------- | ---------------------------------------------------------------- |
| `motor/` | Motor interface, abstract bases, simulation wrappers, and no-ops |

See the [motor README](motor/README.md) for the full abstraction hierarchy and
usage guidance.
